Focus Plan Companion

Opt-in focus tracking. Records only the domain of the site you are on during a running Focus Plan session — never page content, URLs, or history. Everything stays in this browser's storage unless you export it.

Study sites (allowlist)

One domain per line, e.g. khanacademy.org. Subdomains count (e.g. docs.google.com matches google.com only if listed — list the specific domain you want).

Distraction sites (blocklist)

Time on these during a session counts as off-task and can trigger a gentle nudge. Never blocks sites.
